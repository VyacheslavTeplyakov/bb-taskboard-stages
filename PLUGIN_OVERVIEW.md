## Канбан проектов по меткам GitHub

Taskboard Stages показывает этап задачи по метке stage:*, сохраняя независимое состояние issue Open/Closed. У каждого проекта свои названия и порядок колонок. Перемещайте карточки мышью или через меню; агент может выполнять те же операции через bb stageboard.

## Настройка

Сохранение профиля не изменяет GitHub. Наличие меток проверяется отдельно, создание отсутствующих меток выполняется явным действием. Issues без этапа и с ошибочными метками остаются видимыми.

Встроенный навык `stageboard-setup` подключает проект с помощью агента: проверяет доступ, помогает согласовать колонки и ответственного, сохраняет профиль и инструкции проекта. Навык `stageboard` отвечает за обычное чтение и перемещение карточек. Поддерживаются ручное ведение, один агент и существующие роли проекта.

## Требования

Нужны BB 0.47.1 или новее, GitHub-репозиторий проекта и авторизованный GitHub CLI с правами на чтение задач; для изменения этапов нужны права на изменение меток. GitHub Projects и дополнительный трекер не требуются.

Основано на [Taskboard](https://github.com/MateoCerquetella/bb-plugins) под лицензией MIT. Форк имеет отдельные настройки и не переносит данные штатного плагина автоматически.
